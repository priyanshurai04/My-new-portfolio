# Priyanshu Rai — Portfolio Website

Responsive static portfolio built with HTML, CSS and JavaScript. Includes a rotating purple gradient profile ring that glows when clicked.

## Preview locally
Open `index.html` in a modern browser. Internet is used only to load the optional Google Fonts; the page and profile image are included locally.

## Publish on GitHub Pages
1. Upload the **contents** of this folder (not the parent folder) to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for GitHub Pages to provide the site URL.

## Personalize before publishing
In `index.html`, replace:
- `https://www.linkedin.com/` with your actual LinkedIn profile URL.
- `https://github.com/` with your actual GitHub profile/repository URL.
- `hello@example.com` with the email address you want to publish.
- Project cards with accurate project descriptions, screenshots, and links when ready.

The project cards are starter descriptions based on your stated interests; they should be updated to reflect completed work accurately.
